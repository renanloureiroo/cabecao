# Modelos

## `vault/`

Estrutura inicial de um cérebro, copiada pelo `cabecao init` quando o repositório está vazio. O conteúdo chega no marco M1 do [roadmap](../docs/10-roadmap.md), junto com o `init`; a estrutura está descrita em [03 · Modelo de dados](../docs/03-modelo-de-dados.md).

Para um cérebro já preenchido, usado nos testes, veja [`fixtures/vault/`](../fixtures/vault/).
