:::caution[Versão beta]
O Cabeção está em beta (`0.1.0-beta.1`). Ele já funciona no dia a dia, mas o formato e os comandos ainda podem mudar antes da versão 1.0. Use um repositório privado e confira as [novidades](/cabecao/novidades/) ao atualizar.
:::

## Para quem é

Para quem trabalha com agentes de IA (Claude Code, Codex, Cursor e outros) e cansou de repetir as mesmas preferências, decisões e armadilhas a cada sessão nova. O que você ensina numa conversa fica guardado e volta na próxima, em qualquer cliente e em qualquer máquina.

## O que o diferencia

<CardGrid>
  <Card title="Markdown e git seus" icon="document">
    As notas são arquivos `.md` numa pasta comum. Você lê e edita no Obsidian ou em qualquer editor. Não há banco
    de dados que só o Cabeção entende.
  </Card>
  <Card title="Qualquer provedor" icon="seti:git">
    GitHub, GitLab, Bitbucket, Gitea, um servidor seu ou só a sua máquina. O Cabeção usa o git e as credenciais que
    você já tem; não depende da API de nenhum provedor.
  </Card>
  <Card title="Agentes por MCP" icon="puzzle">
    Um servidor MCP local entrega aos agentes busca, grafo, fatos com validade no tempo e ferramentas para gravar
    memórias, com regras que eles não conseguem contornar.
  </Card>
  <Card title="Tudo reversível" icon="random">
    Cada gravação é um commit identificado. `cabecao undo` desfaz uma operação ou uma sessão inteira de um agente,
    sem reescrever o histórico.
  </Card>
</CardGrid>

## Em três comandos

```bash
npm i -g cabecao@beta
cabecao init git@github.com:voce/cerebro.git
cabecao doctor
```

O `init` clona o repositório, cria a estrutura (ou adota o que já existe), monta o índice local e registra o servidor MCP nos clientes de IA que encontrar. O passo a passo está em [Instalação](/cabecao/comecar/instalacao/).
