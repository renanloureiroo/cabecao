## Requisitos

| Programa | Versão | Por quê |
| --- | --- | --- |
| Node.js | 22.16 ou mais nova (linha 22) ou 24 ou mais nova. Recomendado: 24 | O índice local usa o `node:sqlite` com busca de texto (FTS5), que só existe a partir da 22.16. A linha 23 não é aceita. |
| git | 2.38 ou mais novo | O sync integra as mudanças em memória, sem rebase pela metade. |

Confira o que você tem:

```bash
node --version
git --version
```

Com uma versão de Node fora da faixa, o Cabeção não roda e diz o que fazer:

```text
cabecao precisa de Node.js 22.16+ ou 24+. Versão atual: v20.12.2. Atualize em https://nodejs.org
```

## Instalar

O Cabeção está em beta e é publicado no npm com a etiqueta `beta`. Peça essa etiqueta explicitamente.

<Tabs groupId="instalacao">
<TabItem value="t1" label="Global (recomendado)" default>

```bash
npm i -g cabecao@beta
cabecao --version
```

```text
0.1.0-beta.1
```

Com a instalação global, o registro nos clientes de IA aponta direto para o Node e para o arquivo do Cabeção,
sem passar pelo `npx` a cada sessão.

</TabItem>
<TabItem value="t2" label="Sem instalar (npx)">

```bash
npx cabecao@beta init git@github.com:voce/cerebro.git
```

Funciona, mas os clientes de IA ficam registrados como `npx -y cabecao mcp`: cada sessão nova passa pelo `npx`,
que leva de 0,5 a 1,4 s para começar. Para trocar depois, instale globalmente e rode
`cabecao install-client --all`.

</TabItem>
</Tabs>

O pacote não tem dependências de runtime nem binários nativos: é um único bundle JavaScript.

## Crie o repositório do cérebro

Antes do `init`, crie um repositório **vazio e privado** no provedor que você usa (GitHub, GitLab, Bitbucket, Gitea ou um servidor próprio). Copie o endereço do botão "clonar". Pode ser SSH (`git@...`) ou HTTPS.

:::danger[Use um repositório privado]
O código do Cabeção é público; o seu cérebro não deve ser. Em HTTPS de um provedor conhecido, o `init` e o `doctor` avisam se o repositório parecer público.
:::

Se você ainda não quer um remoto, dá para começar só local e ligar um depois. Veja [Criar ou conectar um cérebro](./init.md).
